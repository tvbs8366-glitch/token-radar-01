A token launch radar: every protocol that records no token yet, ranked by what its token would be worth, with a concrete farm plan for each one. The implied value follows only from the snapshot's own figures — TVL, seven-day growth, how long the protocol has run with no token, and how many chains it runs on — and protocols whose token already trades are kept apart at the market's own value.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input token-radar-01-kit/input/snapshot.json
```
